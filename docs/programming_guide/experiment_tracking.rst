############################
実験トラッキング
############################

FLARE は、主要な実験トラッキングシステムである MLflow、Weights & Biases、TensorBoard とシームレスに統合され、メトリクスの包括的なモニタリングを容易にします。

分散型と集中型のトラッキング構成を選択できます:

- **分散型トラッキング**: 各クライアントが自身のメトリクスと実験トラッキングサーバーをローカルで管理し、トレーニングメトリクスのプライバシーを維持します。ただし、この構成では異なるサイト間でデータを比較する能力が制限されます。
- **集中型トラッキング**: すべてのメトリクスが中央の FL サーバーにストリーミングされ、そこから選択したトラッキングシステムにデータがプッシュされます。この構成は、効果的なサイト横断のメトリクス比較をサポートします。

クライアントの実行タイプごとに異なるソリューションを提供しています。Client API の場合は、対応する実験トラッキング API を使用してください。Executor または Learner の場合は、実験トラッキングの LogWriter を使用してください。
