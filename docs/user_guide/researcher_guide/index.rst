################
研究論文
################

NVIDIA FLARE は、医用画像、連合最適化、プライバシー分析、大規模言語モデルといった分野の
査読付き研究で利用されてきました。リファレンス実装は
`GitHub の research ディレクトリ <https://github.com/NVIDIA/NVFlare/tree/main/research>`_
で公開されています。

発表済みの研究
==============

- `FedNCA -- Equitable Federated Learning with NCA <https://github.com/NVIDIA/NVFlare/tree/main/research/FedNCA>`_ (MICCAI 2025)
- `FedBPT -- Efficient Federated Black-box Prompt Tuning for LLMs <https://github.com/NVIDIA/NVFlare/tree/main/research/fed-bpt>`_ (ICML 2024)
- `ConDistFL -- Conditional Distillation from Partially Annotated Data <https://github.com/NVIDIA/NVFlare/tree/main/research/condist-fl>`_ (DeCaF 2023)
- `FedOBD -- Opportunistic Block Dropout for Large-scale Neural Networks <https://github.com/NVIDIA/NVFlare/tree/main/research/fedobd>`_ (IJCAI 2023)
- `Fair Federated Medical Image Segmentation <https://github.com/NVIDIA/NVFlare/tree/main/research/fed-ce>`_ (CVPR 2023)
- `One-shot Vertical FL with Limited Overlapping Samples <https://github.com/NVIDIA/NVFlare/tree/main/research/one-shot-vfl>`_ (ICCV 2023)
- `FedSM -- Closing the Generalization Gap of Cross-silo FL <https://github.com/NVIDIA/NVFlare/tree/main/research/fed-sm>`_ (CVPR 2022)
- `Quantifying Data Leakage in Gradient Inversion Attacks <https://github.com/NVIDIA/NVFlare/tree/main/research/quantifying-data-leakage>`_ (IEEE TMI 2022)
- `Auto-FedRL -- Federated Hyperparameter Optimization <https://github.com/NVIDIA/NVFlare/tree/main/research/auto-fed-rl>`_ (ECCV 2022)
- `FedBN -- Federated Learning on Non-IID Features <https://github.com/NVIDIA/NVFlare/tree/main/research/fed-bn>`_ (ICLR 2021)
- `Privacy-preserving Federated Brain Tumour Segmentation <https://github.com/NVIDIA/NVFlare/tree/main/research/brats18>`_ (MLMI 2019)
