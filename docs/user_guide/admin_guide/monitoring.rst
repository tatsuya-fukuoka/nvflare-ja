モニタリング
**********************

NVIDIA FLARE は、連合学習ジョブのジョブおよびシステムライフサイクルのメトリクスを追跡するためのシステムモニタリング機能を提供します。この機能により、FLARE の運用に関する包括的なシステムレベルのモニタリングと可視化が可能になります。

概要
========

モニタリングシステムは、トレーニングメトリクスではなくシステムレベルのメトリクスに焦点を当てており、以下に関する洞察を提供します:

* ジョブライフサイクルイベント
* システムパフォーマンスメトリクス
* リソース使用率
* ネットワーク統計

これは、トレーニングメトリクスではなくシステムレベルのメトリクスに焦点を当てている点で、機械学習の実験トラッキングとは異なります。

主要コンポーネント
--------------------------------------

モニタリングシステムは、以下のコンポーネントを活用します:

* StatsD Exporter: システムメトリクスを収集・エクスポートします
* Prometheus: メトリクスをスクレイピングして保存します
* Grafana: 収集したメトリクスを可視化します

これらのコンポーネントが連携して、完全なモニタリングソリューションを提供します:

1. FLARE のジョブおよびシステムイベントがキャプチャされる
2. StatsD Exporter がこれらのイベントを処理する
3. Prometheus が StatsD Exporter からメトリクスをスクレイピングする
4. Grafana が可視化とダッシュボードを提供する

設定
--------------

詳細な設定手順とセットアップ手順については、:github_nvflare_link:`Monitoring README <examples/advanced/monitoring/README.md>` を参照してください。

設定には以下が含まれます:

* StatsD Exporter のセットアップ
* Prometheus の設定
* Grafana のインストールと設定
* FLARE モニタリングコンポーネントのセットアップ

可視化
----------------

Grafana のダッシュボードは、収集されたメトリクスの視覚的な表現を提供します。これには以下が含まれます:

* ジョブのステータスと進捗
* システムリソースの使用状況
* ネットワーク統計
* コンポーネントの健全性

利用可能なダッシュボードとメトリクスの詳細については、:github_nvflare_link:`Monitoring README <examples/advanced/monitoring/README.md>` を参照してください。

まとめ
------------

モニタリングシステムは以下を提供します:

* FLARE の運用に対するリアルタイムの可視性
* システムレベルのメトリクス追跡
* 包括的な可視化機能
* 業界標準のモニタリングツールとの統合

セットアップ、設定、使用方法の詳細については、:github_nvflare_link:`Monitoring README <examples/advanced/monitoring/README.md>` を参照してください。
