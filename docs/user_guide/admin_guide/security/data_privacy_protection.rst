データプライバシー保護
==============================================
連合学習の活動は、サーバーと FL クライアント間のタスクベースのやり取りによって行われます。サーバーはクライアントにタスクを発行し、クライアントはタスクを処理して結果をサーバーに返します。NVFLARE には、タスクデータと結果を処理するための汎用的なデータ :ref:`フィルタリングメカニズム <filters>` が備わっています:

    - サーバー側: タスクデータがクライアントに送信される前に、ジョブで定義された "task_data_filters" が実行されます。
    - クライアント側: クライアントがタスクデータを受信し、処理のためにエグゼキューターに渡す前に、NVFLARE フレームワークがジョブで定義された "task_data_filters" を適用します。
    - クライアント側: エグゼキューターによるタスクの実行後、生成された結果をサーバーに返送する前に、NVFLARE フレームワークが "task_result_filters" を結果に適用してからサーバーに送信します。
    - サーバー側: クライアントからタスク結果を受信した後、処理のためにコントローラーに渡す前に、NVFLARE フレームワークが設定された "task_result_filters" を適用します。

このメカニズムは、クライアント側でのデータプライバシー保護の目的で使用されてきました。例えば、集約のためにサーバーへ送信する前に、モデル重みに差分プライバシーフィルターを適用できます。

NVFLARE には github_nvflare_link:`よく使われるプライバシー保護フィルター <nvflare/app_common/filters>` がいくつか実装されています。
