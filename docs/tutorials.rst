チュートリアル
============================

NVFLARE による連合学習(Federated Learning, FL)プログラミングの学習に役立つさまざまなリソースが用意されています:

ビデオチュートリアル
----------------------------------------

- ディープラーニングと従来型の機械学習向けの FLARE の簡単な紹介。
- CIFAR10 の分類や Kaplan-Meier 生存分析などの例を含みます。
- `ビデオの視聴とコードの閲覧 <https://nvidia.github.io/NVFlare/>`_

チュートリアルカタログ
--------------------------------------------

- 経験レベル、フレームワーク、アルゴリズム、アプリケーション、業界、API、プライバシーアルゴリズムで、豊富なサンプル群を絞り込みながら閲覧できます。
- `カタログを見る <https://nvidia.github.io/NVFlare/catalog/>`_

- `POC Tutorials: <https://github.com/NVIDIA/NVFlare/tree/main/examples/tutorials/setup_poc.ipynb>`_

- `Job Recipe: Simplified job creation <https://github.com/NVIDIA/NVFlare/tree/main/examples/tutorials/job_recipe.ipynb>`_

自己学習
------------------

- 詳細なチュートリアルやリソースを含む、NVIDIA FLARE を自分のペースで学ぶための豊富な教材。
- 包括的なガイドについては、:ref:`self_paced_training` のドキュメントを参照してください。
- 全12章のコース: 連合学習アプリケーションの実行、アルゴリズム、システムアーキテクチャ、実験トラッキング、システムモニタリング、産業応用まで、FLARE を深く掘り下げて解説します。
- 各ノートブックは独立して実行できますが、順番に学習することを推奨します。
- 100 以上のノートブックと 80 以上のビデオ: FLARE による連合学習の徹底的なガイドです。

.. note::

   注記: 自己学習用のトレーニングノートブックは NVFlare 2.6 で開発されました。すべての内容が最新の API を反映しているわけではなく、一部のサンプルは新しいバージョンでは調整が必要な場合があります。
