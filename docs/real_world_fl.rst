##################################################
実世界のフェデレーテッドラーニング
##################################################

このセクションでは、NVIDIA FLARE を使って FL システムをデプロイし運用する方法を説明します。
ここではリファレンスアプリケーションを用いて、FLARE コンソールと FLARE API を通じたシステムの
プロビジョニングと基本的な運用を示します。クラウドへのデプロイについては :ref:`cloud_deployment` を参照してください。

プロジェクトのプロビジョニングやスタートアップキットの配布に必要な情報を収集するのに役立つ
:ref:`nvflare_dashboard_ui` のセットアップ方法については、:ref:`dashboard_api` を参照してください。

カスタムコンポーネントを含むアプリで何ができるか、また Controller API と Worker API がもたらす
柔軟性の詳細については、:ref:`programming_guide` を参照してください。

認可ポリシーの設定については、:ref:`フェデレーテッド認可 <federated_authorization>` を参照してください。

`Clara Train <https://docs.nvidia.com/clara/clara-train-sdk/>`_ や
`MONAI <https://github.com/Project-MONAI/tutorials/tree/master/federated_learning/nvflare>`_
と統合した :github_nvflare_link:`サンプルアプリケーション <examples>` も参照して、
システムの機能とその運用方法を確認できます。
