連合学習とは?
============================

連合学習(Federated Learning)は、それぞれが独自のローカルデータセットを持つ複数のクライアント間でトレーニングを行う分散学習パラダイムです。
これにより、機密性の高いローカルデータを共有することなく、共通の堅牢なモデルを作成でき、データのプライバシーとセキュリティの課題解決に役立ちます。

FLサーバーは、初期モデルをクライアントに送信することでコラボレーションをオーケストレーションします。クライアントはローカルデータでトレーニングを行い、
モデルの更新を送り返してグローバルモデルへと集約します。複数のラウンドを経て、堅牢なグローバルモデルが構築されます --
その間、生データがその発生源から外に出ることは一切ありません。

.. image:: resources/fl_diagram.png
    :height: 450px

**連合学習の種類:**

- **水平FL** -- クライアントは同じ特徴量に対して異なるデータサンプルを保持する
- **垂直FL** -- クライアントは重複するデータサンプルに対して異なる特徴量を保持する
- **Swarm Learning** -- 中央サーバーなしでクライアントが集約を行う分散型FL

NVIDIA FLAREとは?
==============================

**NVIDIA FLARE** (NVIDIA Federated Learning Application Runtime Environment) は、ドメインに依存しない、オープンソースで
拡張可能なPython SDKであり、既存のML/DLワークフローに連合学習を簡単に導入できます。

**数分で始められます** -- FLAREは、データサイエンティストが既存のトレーニングコードを最小限の労力で
連合学習化できるように設計されています:

- **Client API** を使えば、既存のトレーニングスクリプトに数行追加するだけで済みます
- **Job Recipe API** を使えば、事前構築済みのFLアルゴリズムを選んですぐに実行できます
- **FL Simulator** を使えば、デプロイ前にすべてをローカルでテストできます

以下は、わずか数行で完結する連合平均(federated averaging)ジョブの完全な例です:

.. code-block:: python

    from nvflare.app_opt.pt.recipes import FedAvgRecipe
    from nvflare.recipe import SimEnv

    recipe = FedAvgRecipe(
        name="my-first-fl-job",
        min_clients=2,
        num_rounds=5,
        model=MyModel(),
        train_script="train.py",
    )
    run = recipe.execute(SimEnv(num_clients=2))

FLAREは **PyTorch、TensorFlow、XGBoost、scikit-learn**、およびPythonで実行できるあらゆるフレームワークをサポートしています。
1台のラップトップ(シミュレーター)から、数千の分散サイト(本番環境)、さらには数百万のエッジデバイスまで、
すべて同じジョブ定義でスケールします。

なぜNVIDIA FLAREなのか?
================================

NVIDIA FLAREは、研究用プロトタイピングだけでなく、**実世界の本番環境デプロイメント**\ のために構築されています。

**研究専用フレームワークとの比較:**
研究志向のFLフレームワークとは異なり、FLAREは完全な本番環境スタックを提供します: PKI証明書による
セキュアなプロビジョニング、サイトごとのきめ細かな認可ポリシー、監査ログ、ハードウェアTEEによる
コンフィデンシャルコンピューティング、そしてDocker、Kubernetes、クラウド環境向けのデプロイメントツールです。
病院、国立研究所、金融機関を含む組織が、今日、本番環境でFLAREを運用しています
(:ref:`業界ユースケース <industry_use_cases>` を参照)。

**主な差別化要因:**

- **最小限のコード変更** -- Client APIにより、コードを書き直すことなく、数行追加するだけで
  既存のトレーニングスクリプトを連合学習化できます
- **本番環境レベルのセキュリティ** -- TLS/mTLS、サイトごとの認可ポリシー、差分プライバシー、準同型暗号、
  ハードウェアベースのコンフィデンシャルコンピューティング(AMD SEV-SNP、NVIDIA GPU TEE)
- **スケール** -- 2サイトから、階層型アーキテクチャによる数百万のエッジデバイスまで
- **フレームワーク非依存** -- PyTorch、TensorFlow、XGBoost、scikit-learn、HuggingFace、NeMo、Flower
- **本番環境での実績** -- ヘルスケアコンソーシアム、国家安全保障関連の研究所、金融機関で利用されています

主な機能
================

**生産性のために**

- **Client API** -- 既存のトレーニングコードを最小限の変更で連合学習化
- **Job Recipe API** -- FedAvg、FedProx、SCAFFOLD、XGBoost、Cyclicなどの事前構築済みレシピ
- **FL Simulator** -- 1台のマシンでの迅速なプロトタイピング
- **POCモード** -- 1台のホスト上での連合ネットワークのマルチプロセスシミュレーション
- **FLARE API** -- Pythonコードやノートブックからのジョブの実行と監視
- **ダッシュボード** -- プロジェクトのセットアップとデプロイメント成果物配布のためのWeb UI
- **実験トラッキング** -- MLflow、Weights & Biases、TensorBoard

**セキュリティとプライバシーのために**

- **セキュアなプロビジョニング** -- TLS証明書ベースの認証
- **認可ポリシー** -- サイトが管理するきめ細かな認可
- **プライバシー保護** -- 差分プライバシー、準同型暗号、Private Set Intersection
- **コンフィデンシャルコンピューティング** -- AMD SEV-SNPとNVIDIA GPUをサポートするハードウェアベースのTEE
- **監査ログ** -- 説明責任のための完全な監査証跡

**スケールのために**

- **フレームワーク非依存** -- PyTorch、TensorFlow、XGBoost、scikit-learnなど
- **クロスサイロからエッジまで** -- 少数の病院サイトから数百万のモバイルデバイスまで
- **階層型アーキテクチャ** -- 大規模デプロイメント向けのマルチリージョン・階層型FL
- **マルチジョブ実行** -- リソース管理を伴う並行ジョブ実行
- **サードパーティ統合** -- 外部システムとのシームレスな統合のためのFlareAgent

**カスタマイズのために**

- **イベント駆動プラグインアーキテクチャ** -- FLAREのあらゆるレイヤーは、イベントシステムと
  コンポーネントプラグインを通じてカスタマイズ可能です。FLワークフローの任意の段階をインターセプト、変更、拡張できます
- **仕様ベースのAPI** -- コントローラー、アグリゲーター、フィルター、エグゼキューターなどについて、
  明確に定義された仕様に従って代替実装を構築できます
- **プラガブルなコンポーネント** -- アプリケーションコードを変更することなく、集約戦略、プライバシーフィルター、
  モデルパーシスター、通信バックエンドを差し替え可能
- **豊富なサンプル** -- 出発点として使える、FLアルゴリズム、ワークフロー、アプリケーションサンプルの広範なライブラリ

2.8.0の新機能
==========================

NVIDIA FLARE 2.8.0では、デプロイメント自動化、CLI運用、
マルチスタディサポート、本番環境向けの堅牢化が拡充され、さらにオンプレミスおよびクラウド環境向けの
DockerとKubernetesのジョブランチャー、新しいマルチモーダルおよび研究サンプルが追加されました。

**ハイライト:**

- **モダンなNVFlare CLI**: ``job``、``system``、``config``、
  ``recipe``、``cert``、``package``、``deploy`` コマンドグループが拡充され、自動化のための
  JSON出力とスキーマサポートを提供
- **分散プロビジョニング**: 参加者管理の証明書リクエストにより秘密鍵をローカルに保持したまま、
  Project Adminが署名済みパッケージとルートCAの信頼を承認
- **DockerおよびKubernetesジョブランチャー**: サイトはプロセス、Docker、またはKubernetesの
  ジョブランチャーを構成でき、サブプロセスジョブ、ジョブコンテナ、またはスタディスコープの
  データセットマウントを持つ分離されたジョブPodを利用可能。AWS、Azure、GCP上の
  Kubernetesデプロイメントにも対応
- **マルチスタディサポート**: スタディスコープのセッション、認可、CLIコマンド、
  ローカルPoCワークフローにより、運用コンテキストやデータアクセスコンテキストを混在させることなく、
  1つのデプロイメントで複数のコラボレーションをホスト可能
- **ライブログストリーミング**: ジョブ実行中にクライアントのジョブログをサーバーへストリーミングし、
  リモートデバッグのループを短縮

完全なリリースノートは :doc:`release_notes/flare_280` を参照してください。
過去のリリースについては :doc:`release_notes/previous` を参照してください。

製品ライン
====================

FLAREは3つの製品カテゴリで構成されています:

**FLARE Core**
    完全な連合学習プラットフォーム: 通信インフラストラクチャ、ワークフロー、コントローラー、
    Client API、Recipe API、FL Simulator、プロビジョニング、デプロイメント、管理ツール。

**FLARE Confidential AI**
    ハードウェアベースのセキュリティを備えたコンフィデンシャル連合AI。Trusted Execution Environment
    (AMD SEV-SNP、Intel TDX)とNVIDIA GPUコンフィデンシャルコンピューティングを活用し、
    エンドツーエンドのIP保護を実現します。オンプレミスとAzureクラウドの両方のデプロイメントをサポートします。

**FLARE Edge**
    エッジにおける連合学習。階層型アーキテクチャ、非同期集約(FedBuff)、デバイスシミュレーション、
    AndroidおよびiOS向けモバイルSDK(ExecuTorch経由)により、数百万のデバイスをサポートします。
